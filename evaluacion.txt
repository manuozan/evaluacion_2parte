1) Desarrolle como llegamos a este repositorio
Respuesta: Desde descifrar el jwt token, a traves de la web https://jwt.io/

2) Qué es un JWT? Cuáles son sus partes?
Respuesta: 
- header: aca dice como esta codificado, tipo de codificacion y algoritmo
- playload: aca corresponde al bloque de la data que se envia
- signature: esta es la signatura de la encriptografia

3) Cuál es la diferencia entre Git y Github?
Respuesta:
- git es el gestor de versiones
- github, es el espacio en la web donde se almacenan los repositorios

4) Cómo podría fusionar las ramas? Qué ocurriría al intentarlo?
- con un pull request p con git pull desde otra rama. (pull = fetch + merge)
- esto generaria conflictos, ya que hay una diferencia con las versiones.
- al realizar el merge, se va a tener que decidir que version queda.
